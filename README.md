# PARTY-UP 📅

一个界面优雅、交互流畅的社交组局与日历管理微信小程序。

项目采用原生微信小程序框架结合**微信云开发（CloudBase）**构建，实现了从前端视觉交互到后端数据存储、云函数触发、消息推送的完整闭环。

## 🌟 核心特性

- **高级日历视图系统**：
  - **周视图（时间轴）**：直观的时间轴展示，精确到小时的事件色块。**独创的事件碰撞算法**：当多个活动时间重叠时，自动计算等比宽度并左右并排错开显示，绝不遮挡。
  - **月视图**：全局概览，自适应的日历网格，精美的小圆点阵列标记事件（最多支持完美排列 6 个事件点）。
  - **无缝手势交互**：全面支持左右滑动切换日期和月份，内置丝滑的过渡动画。
- **优雅的设计系统**：
  - 采用莫兰迪低饱和度色板（暖棕、灰绿、雾蓝等），高级感满满。
  - 支持深/浅色模式（Dark Mode）无缝自动切换。
- **完善的组局与事件管理**：
  - 支持创建、编辑、删除单次或**每周/每月的重复事件**。
  - 自定义标题、选择分类（🏋️健身/🍺聚饮/⛰️户外）、设定起止时间与具体地点。
  - 支持“私人事件”选项，保障个人及特定群组的隐私。
- **社交与参与闭环**：
  - **一键邀请**：不仅支持微信默认分享卡片，还支持**生成极简风格的高清邀请海报**（结合 Canvas 2D 与小程序太阳码），扫码直达活动详情。
  - **加入活动**：好友扫码或点击卡片后，一键点击“加入活动”，实时在参与者列表中展示微信头像。
- **小组专属聚会空间**：
  - 组建好友圈子，发起民主投票决定聚会地点。
  - 组长拥有强力控制台，随时结票并手动定标。
  - 组内可直接发起私密专属局，群组成员共享活动看板。
- **智能订阅与服务通知**：
  - 结合微信订阅消息 API 与定时触发的**云函数**。
  - 支持活动创建者或参与者订阅提醒，在活动开始前（如提前 15 分钟、1 小时）通过微信“服务通知”准时向所有参与者下发提醒，确保无人缺席。
- **云端个人中心**：
  - 完整接入微信登录授权。
  - 云数据库实时同步用户数据，按“即将到来”、“已结束”归档并统计用户的社交活跃度。

## 🛠 技术栈

- **前端框架**：原生微信小程序 (WXML, WXSS, JS)
- **后端架构**：微信云开发 (CloudBase)
- **数据库**：云数据库 (Cloud Database)
- **服务端逻辑**：云函数 (Cloud Functions) 与定时触发器 (Triggers)
- **样式**：CSS Variables, Flexbox 弹性布局算法

## 🚀 部署与运行指南

1. **导入项目**
   - 使用「微信开发者工具」导入该项目目录。
   - 填写你自己的微信小程序 `AppID`。
2. **开通云开发**
   - 在开发者工具顶部点击“云开发”按钮，开通环境（如果还未开通）。
   - 将左侧目录树中的 `cloudfunctions` 文件夹右键指定为你的当前云环境。
3. **数据库配置**
   - 在云开发控制台 -> 数据库，创建以下两个集合（Collection）：
     - `users` （并将权限设置为“所有用户可读，仅创建者可读写”）
     - `events` （并将权限设置为“所有用户可读，仅创建者可读写”）
4. **部署云函数**
   - 右键点击 `cloudfunctions/sendReminders` 文件夹，选择“上传并部署：云端安装依赖（不上传node_modules）”。
   - 右键点击 `cloudfunctions/sendReminders/config.json`，选择“上传触发器”（用于实现定时消息推送）。
5. **编译预览**
   - 点击编译，即可在模拟器中体验，或点击“预览”在真机上扫码体验完整功能。

## 📦 版本历史 (Changelog)

### v1.4.0 (当前版本) - 循环事件与小组日程
- **循环与私密事件**：支持创建每周/每月的重复活动及私密活动，并支持一键删除/管理整个系列的循环事件。
- **小组专属活动**：小组内可直接发起内部活动，组内新增“即将到来的活动”面板，日程一目了然。
- **生成邀请海报**：日历活动与小组均支持一键生成极简风邀请海报与微信太阳码，扫码直达。
- **投票控制**：强化组长权限，支持随时手动结束小组投票并指定最终活动地点。
- **体验优化**：新建活动标题自动填充、弹窗UI交互升级、新增创建者快捷编辑等细节优化。

### v1.3.0 - 社交分享与视觉体验升级
- 新增组局海报及太阳码生成功能（Canvas 2D 绘制）。
- 整体 UI 元素及弹窗风格的极简高阶化重构。

### v1.2.0 - 底层架构全面大升级
- **账号体系重构**：全面接入微信原生 OpenID，支持静默无感登录，彻底解决本地缓存导致的用户丢失及头像刷新问题。
- **数据安全防线**：所有数据库写操作（增删改）全面迁移至 `eventService`、`groupService` 等云函数。前端安全规则缩紧至“所有用户可读（不可写）”，彻底杜绝客户端越权篡改。
- **性能深度优化**：
  - 日历页与「我的」页面引入服务端智能分页（Pagination）加载。
  - 缩减单次请求的数据量，大幅降低流量消耗与渲染卡顿。
- **Bug 修复**：修复了历史活动的创建者和参与者数据显示异常、超时等疑难问题。

### v1.1.1 - 交互细节优化
- 优化「去哪玩」交互体验：
  - 新增目的地列表的拖拽排序功能。
  - 升级投票截止时间设置，支持自定义开关与时间选择。
- 优化大量 UI 细节与过渡动画，提升整体视觉质感。

### v1.1.0 - 全新「去哪玩」小组投票功能

- **投票机制**：每人可发起地点提案（Places），全组成员进行民主投票。
- **评论系统**：围绕具体的活动或提案，支持实时的留言讨论。

## 🎨 界面设计理念

Party Up 摒弃了传统日程软件枯燥的条目式设计，将每一次聚会都视为一张精美的卡片。无论是圆润的边缘、细腻的阴影、还是克制的色彩搭配，都旨在消除管理时间的焦虑感，让“组局”变成一件轻松、令人期待的事情。
