# PARTY-UP 📅

一个界面优雅、交互流畅的社交日历微信小程序（Web 预览版）。

目前采用纯前端技术栈（Vite +原生 HTML/CSS/JS）实现了完整的 UI 视觉与核心交互逻辑，为后续正式转换为微信原生小程序奠定了坚实的基础。

## 🌟 核心特性

- **三种视图无缝切换**：
  - **周视图**：默认主页，直观的时间轴展示，精确到小时的事件色块。
  - **月视图**：全局概览，小圆点高亮标记有事件的日期。
  - **年视图**：12个月缩略网格，快速跳转定位。
- **流畅的交互体验**：全面支持左右/上下滑动切换日期和月份，内置平滑的过渡动画。
- **优雅的设计系统**：采用莫兰迪低饱和度色板（暖棕、灰绿、雾蓝等），支持深/浅色模式无缝切换。
- **完善的事件系统**：
  - 支持创建、编辑、删除事件。
  - 支持自定义标题、选择分类（🏋️健身/🍺聚饮/⛰️户外）、设定起止时间与地点、设置提醒。
- **社交与参与**：
  - 事件详情页展示完整参与者列表与发起人信息。
  - 支持“我要加入”和“退出”活动。
- **用户个人中心**：
  - “我的”页面展示用户统计数据（全部活动/即将到来/已结束）。
  - 支持未登录用户的模拟登录体验。

## 🛠 技术栈

- **开发工具**：Vite
- **样式**：Vanilla CSS (CSS Variables, Flexbox, Grid)
- **逻辑**：Vanilla JavaScript (ES Modules)
- **状态管理**：基于 `localStorage` 的自定义响应式 Store

## 🚀 快速启动 (本地开发)

确保你已经安装了 Node.js。

1. **安装依赖**
   ```bash
   npm install
   ```

2. **启动开发服务器**
   ```bash
   npm run dev
   ```

3. **预览**
   浏览器会自动打开 `http://localhost:3000`，你可以直接在电脑上看到居中展示的移动端模拟器效果。

## 📱 后续计划 (转为真实微信小程序)

本项目的所有 CSS 样式和 JS 逻辑都经过专门设计，极易迁移至原生微信小程序：
- 将现有的 DOM 操作重构为 WXML 数据绑定。
- `localStorage` 数据接入微信云开发（云函数 + 云数据库）。
- 接入真实微信登录 (`wx.login`)、订阅消息与原生分享卡片。
